# The Gens Player Manual

This is a player-facing manual for *Gens* — a synthesis of the full game
design corpus under [`docs/design/`](../design/), written to read like an
actual game manual rather than an engineering specification. It explains what
the game is, how it plays, and what every major system does for you as a
player, without the cross-references, supersession notes, and open questions
that make the design documents themselves better suited to implementation
than to reading start-to-finish.

**A note on scope:** this manual describes the full intended design — the
complete game *Gens* is being built toward, not necessarily what's playable
today. For the authoritative, continually-updated account of what's actually
implemented right now, see the
[Comprehensive Build Roadmap](../engineering/gens-comprehensive-build-roadmap.md).
Where this manual and the design documents disagree on how a system works,
the [Design Authority Registry](../gens-design-authority-registry.md)
settles which document is authoritative.

## How this manual was built

Each chapter condenses several related design documents into player-facing
prose, following the [Design Authority Registry](../gens-design-authority-registry.md)
wherever two design documents describe the same mechanic differently. Every
chapter links out to the specific design documents it draws from, for readers
who want the full mechanical detail behind any system.
