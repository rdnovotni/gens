# GENS — System Design: Named Roads & Trade Itineraries
*The real, specific infrastructure sitting underneath two abstractions this project has been quietly relying on without ever naming: Travel and Starting Regions' own Distance Tier lookup (Italian Heartland's own table already credits short travel times to "well-established Roman roads and shipping lanes" without saying which ones), and the Cursus Publicus — the real imperial relay-and-post system Correspondence & Letters' transit-time model has been implicitly assuming exists. Distinct from Public Works & Euergetism's own generic, single-settlement Roads category, this document is about the real, individually named arteries — the Via Appia, the Via Egnatia, the Via Domitia — that actually tie this project's own regional roster together, and that a household can, per real Roman practice, own, maintain, and even extend a piece of.*

## 1. Scope & Role — Distinct from Public Works' Generic Roads

Public Works & Euergetism already gives a settlement a generic "Roads" category — a real, direct improvement to that settlement's own Travel efficiency and Trade Route effectiveness, funded like any other civic infrastructure. That document's own Open Questions are honest about what it never resolved: "whether a household can fund infrastructure (particularly a road) connecting two separate settlements, rather than a single work located entirely within one, isn't addressed." Estate & Settlement carries a matching, explicitly parked gap of its own — "formalized road/river/coast trade-proximity bonuses... considered during this polish pass and set aside." This document is the answer to both.

**A Named Road is real, specific, and spans regions rather than sitting inside one settlement's own boundary.** The Via Appia doesn't belong to Capua or to Rome — it belongs to the corridor between them, and to everyone who travels, trades, or corresponds along it. This document's entire premise is that Travel's own Distance Tier ratings and Correspondence & Letters' own transit times were never actually abstract — they were always secretly reading off real infrastructure like this, and this document simply names it and makes it something a player can see, invest in, and in the rarest cases, build.

**What doesn't move here:** Public Works & Euergetism's own generic, settlement-scoped Roads category stays exactly as written — it's still the right tool for a purely local street or a settlement's own last-mile connection to whichever Named Road happens to pass nearby.

## 2. The Cursus Publicus — Naming the System Already Implied

The real, historically attested imperial state relay system — a network of way-stations along the empire's own major roads, supporting official couriers, government business, and, per real practice, occasionally privileged private correspondence riding alongside it. This document gives Correspondence & Letters' own transit-time model and Travel's own distance calculations the concrete physical infrastructure they were always quietly assuming: a route running along an active, well-maintained Named Road with a functioning Cursus Publicus relay chain resolves at genuinely faster transit time and lower en-route risk than the same real distance covered off the network entirely — the mechanical difference between "the road exists" and "the road exists, is maintained, and has working relay stations every so many miles."

Access to the Cursus Publicus proper is historically an official privilege — a magistrate, a Legate, or a household with sufficient standing and a genuine official purpose can use it; an ordinary private courier or merchant travels the same physical road but without that same relay-chain speed advantage, unless a specific Diploma (a real, attested Roman travel permit) has been secured, itself a small, real Politics & Patronage-adjacent favor worth calling in.

## 3. The Named Road Roster

A representative, non-exhaustive set of real, historically real arteries, deliberately chosen to give as many of this project's own existing regional documents a concrete, shared physical connection as possible:

| Road | Real Route | Regions Connected |
|---|---|---|
| **Via Appia** | Rome → Capua → Brundisium | The spine of the Italian Heartland's own document — already the road Capua, Rome, and (per this document's own Servile Wars companion) Spartacus's own revolt are all implicitly tied to; the real embarkation route toward the Greek East and beyond |
| **Via Egnatia** | Dyrrachium/Apollonia → Thessalonica → Byzantium | The great East-West land bridge tying the Balkans, Greek East, and Anatolia together — the real, physical reason those three regions' own documents can plausibly reach each other overland rather than only by sea |
| **Via Flaminia** | Rome → Ariminum (the Adriatic coast) | Rome's own real northward artery, the natural land route toward the Alpine Provinces and, beyond them, Gallic Frontier |
| **Via Domitia** | Italy → Gallic Frontier's own southern coast → the Iberian border | A real, direct physical link between three separate regional documents — Italian Heartland, Gallic Frontier, and Iberian Colony — via one continuous named road |
| **Via Augusta** | The Iberian Colony's own extension of the Domitia, running the length of Hispania | Iberian Colony's own internal spine, tying its own coastal and interior settlements together |
| **Via Maris** | The ancient Levantine coastal route, pre-dating Roman rule entirely | Syria/The Levant and Egypt's own real, physical connection, older than Rome itself and simply maintained rather than built by it |
| **The Incense Route** | A real caravan corridor rather than a paved Roman road, running the length of Arabia Felix | The concrete physical infrastructure behind that region's own already-established frankincense-and-myrrh trade wealth |
| **The Royal Road's Roman-era descendant** | Running through Mesopotamia toward Parthia | A real, ancient route (originally a Persian Achaemenid road, centuries older than Rome) still in active use, tying Mesopotamia's own brief provincial window to Parthia's own Great Power presence just beyond it |

Every Named Road is a real, geographically fixed object shared across every playthrough, the same "the location is fixed and real; the living world layered on top of it isn't" principle Starting Regions' own Gazetteer already establishes for individual settlements.

## 4. Owning a Piece of the Road — The Curator Viarum

The direction's own specific ask, answered directly: a household cannot own an entire Named Road, but real Roman practice gives this project exactly the right concrete unit of ownership below that — a **road segment**, a defined stretch of a Named Road passing through or adjacent to a household's own territory, maintained under a real, attested Roman office: **Curator Viarum**, "curator of roads."

- **Funding and maintaining a segment** reuses Public Works & Euergetism's own funding and Inscription mechanics directly (§4, §7 of that document) rather than inventing a parallel system — a household sponsoring its own stretch of the Via Appia is euergetism, applied to a road segment instead of a settlement-bound aqueduct.
- **A maintained segment carries real, standing toll rights**, collected by the same Portitor role Companions & Court Positions already established for customs administration (§4.2 of that document) — a genuine, ongoing Economy & Finance income stream distinct from Public Works' own more diffuse settlement-wide Trade Route benefit, because this income is tied to one specific, ownable stretch of road rather than a whole settlement's general commerce.
- **A well-maintained segment measurably speeds Travel and Correspondence** for anyone passing through it specifically (§2), and a poorly-maintained or neglected one (§7) does the reverse — a household's own road segment is a real, visible, and legible piece of infrastructure other households genuinely benefit or suffer from passing through, not merely a private income source.

## 5. Waystations — Mansiones and Mutationes

The real, physical nodes strung along any Named Road, and a genuine new category of ownable property this project hasn't had before:

- **A Mansio** — a real, attested overnight inn and rest stop, offering food, lodging, and safety for travelers making a longer journey along a Named Road.
- **A Mutatio** — a real, smaller waystation specifically for changing horses, the actual physical mechanism behind the Cursus Publicus's own relay speed (§2).

Either can be built and operated as a genuine, income-generating Property Record (Land Ownership & Real Estate §5's own acquisition framework, extended with a new property type) — a Mansio along a well-traveled stretch of the Via Egnatia is a real, legitimate business, and, per Travel §4's own en-route Event pool, a Character passing through a settlement with a well-run, player- or Notable-Household-owned Mansio nearby draws from a safer, more flavor-weighted event pool on that specific leg rather than the ordinary, danger-weighted default — a concrete, felt reason to actually invest in one beyond its own direct income.

## 6. Trade Itineraries — Planning a Route, Not Just Taking One

The second half of this document's own name, and a direct, concrete extension of Economy & Finance's own Trade Routes section (§7 of that document), which already allows "occasional deliberate route choice" between named regional options without ever giving the player a way to actually see or plan the whole journey as a single object. A real, historically attested inspiration exists for exactly this: ancient itinerary documents (the real Antonine Itinerary and the Peutinger Table both genuinely existed) listed roads, distances, and stops end to end for exactly this planning purpose.

A **Trade Itinerary** is a player-defined, named, multi-leg route explicitly following one or more Named Roads (and, where a sea crossing is unavoidable, a Travel-defined shipping lane) from an origin settlement to a destination — Rome to Brundisium via the Via Appia, then onward by sea to the Greek East, say. Once defined, an Itinerary becomes the concrete object §4's road-segment investment and §5's Mansio ownership actually pay off against directly: a household that has invested in maintaining its own stretch of the Via Appia and operates a Mansio along it sees its *own* Itineraries running that corridor move faster, more safely, and more cheaply than an equivalent route the player has never invested a denarius in — a real, visible, and legible reward for exactly the kind of infrastructure investment this document exists to make possible.

## 7. Maintenance, Decay & Disruption

A Named Road segment carries the same real, ongoing upkeep logic Public Works & Euergetism already established for any other civic infrastructure (§6 of that document) — reading directly against Buildings' own condition-and-decay mechanics, with neglect degrading the segment's own speed and safety benefit over time and, in a severe case, risking a real Scandal for visible disrepair.

**Disruption beyond ordinary neglect** is where this document draws real, direct value from two of this project's own more dramatic systems: a Natural Disaster (a Landslide or Flood specifically) striking a Named Road segment is a real, physical interruption to every Trade Itinerary and every piece of Correspondence routed through it, not merely a local settlement inconvenience — and a Client Kingdom's own Breaking Away (Client Kingdoms & Vassal Rulers §9), or a sufficiently large Servile War (Servile Wars, Slave Revolts & Collective Resistance §6), astride a Named Road corridor can cut that route off entirely for the duration, exactly the real, felt regional consequence Spartacus's own historical revolt actually posed to the Via Appia corridor itself. A household whose own Trade Itinerary runs directly through a region currently experiencing either crisis faces a real, immediate, and legible reason to care about a conflict that might otherwise feel entirely someone else's problem.

## 8. Building a New Road — The Rarest Civic Achievement

The single rarest, highest-prestige tier this document offers, and a real, historically perfect illustration of why it's worth building at all: the Via Appia itself is real-historically named after its own builder, the censor Appius Claudius Caecus — a road literally carrying its founder's own name into the present day, over two thousand years later. This document names **founding a genuinely new Named Road extension** (not merely maintaining an existing segment, per §4, but physically extending the network into previously unconnected territory) as this entire system's own rarest, most prestigious possible civic achievement — reusing Public Works & Euergetism's own Inscription mechanic at its absolute highest tier, and a direct, guaranteed-tier trigger for Epithets, Nicknames & Titles' own Agnomen mechanic (§4 of that document): a household wealthy and ambitious enough to fund an entirely new stretch of road can, per real historical precedent, have it carry their own family's name from that point forward — a genuinely permanent, real, and visible mark on the map itself, distinct from and rarer than any ordinary Monument or Public Work this project has built before.

## 9. Cross-System Integration

- **Public Works & Euergetism:** this document is the direct, cross-settlement answer to that document's own explicitly parked open question; §4 and §8 reuse its funding and Inscription mechanics wholesale rather than inventing parallel ones.
- **Travel, Correspondence & Letters:** §2 supplies the real, concrete infrastructure both documents' own distance and transit-time models were always implicitly reading; a Diploma is a small, real Politics & Patronage favor unlocking genuine Cursus Publicus access.
- **Estate & Settlement:** this document is the direct answer to that document's own explicitly parked trade-proximity-bonus question.
- **Land Ownership & Real Estate:** a Mansio or Mutatio (§5) is a genuine new Property Record type, acquired and operated through that document's own existing framework.
- **Companions & Court Positions:** the Portitor (§4.2 of that document) is the concrete role collecting §4's own road-segment tolls; a Curator Viarum is a natural, small addition to that document's own Senior Position roster.
- **Economy & Finance:** §6's Trade Itinerary is the concrete, plannable object behind that document's own previously abstract "occasional deliberate route choice" on Trade Routes.
- **Natural Disasters, Servile Wars & Collective Resistance, Client Kingdoms & Vassal Rulers:** §7 ties all three documents' own disruptive events directly to a Named Road's own physical, regional consequence, rather than a purely local one.
- **Epithets, Nicknames & Titles:** §8 is a new, top-tier, guaranteed Agnomen trigger, directly modeled on the real historical Via Appia naming precedent.
- **Starting Regions (Italian Heartland, Gallic Frontier, Iberian Colony, Balkans, Greek East, Anatolia, Syria/The Levant, Egypt, Arabia Felix, Mesopotamia):** every one of these documents' own Distance Tier tables and Gazetteer entries now has a real, named physical road or route this document supplies underneath them, resolving a piece of the Starting Regions framework's own long-standing Distance Tier open question.
- **Dynasty Chronicle:** a funded road segment, a well-run Mansio, and especially a newly founded and family-named road extension (§8) are all guaranteed, tiered Chronicle material.

## 10. Data Model

```
NamedRoad {
  namedRoadId,
  name,                                   // "viaAppia" | "viaEgnatia" | "viaFlaminia" | "viaDomitia" |
                                         // "viaAugusta" | "viaMaris" | "incenseRoute" | "royalRoadDescendant"
  connectedRegionIds: [ ... ],
  overallCondition,                        // aggregate, derived from its own segments
}

RoadSegment {                              // §4
  segmentId,
  namedRoadId,
  locationDescriptor,                       // which real stretch, e.g. "Capua to Beneventum"
  curatorViarumCharacterId,                    // nullable — the household appointee/patron maintaining it
  fundingHouseholdOrSocietasId,
  condition,                                 // reads Buildings' own decay mechanics
  tollIncomeActive: bool,
  hasInscription: bool,
  disruptedBy,                                // nullable — "naturalDisaster" | "clientKingdomBreakaway" | "servileWar"
}

Waystation {                                // §5
  waystationId,
  type,                                       // "mansio" | "mutatio"
  namedRoadId, nearestSettlementId,
  ownerId,                                     // links to Land Ownership & Real Estate's own PropertyRecord
  travelEventPoolModifier,                      // safer/flavor-weighted pool for the adjacent leg
}

TradeItinerary {                            // §6
  itineraryId,
  ownerHouseholdId,
  legs: [ { namedRoadId, segmentIds: [ ... ] } | { shippingLaneId } ],
  originSettlementId, destinationSettlementId,
  investmentBonusActive: bool,                   // true where the owner holds relevant RoadSegment/Waystation investment
}

NewRoadFoundingRecord {                      // §8
  foundingHouseholdId,
  namedRoadExtensionName,                        // typically the founding family's own name, per real precedent
  connectingSettlementIds: [ ... ],
  agnomenGranted: true,
  chronicleEligible: true,
}
```

## 11. Open Questions

- **All numeric sizing**, per this project's standing convention — Cursus Publicus speed bonuses, toll income rates, Mansio/Mutatio construction costs, and a founded road's own construction cost/prestige threshold are all unsized.
- **Whether a household can hold more than one Road Segment simultaneously**, and whether doing so on the same Named Road at different points offers any compounding benefit beyond the sum of the two individually.
- **Diploma acquisition.** §2 flags official Cursus Publicus access as securable through "a small, real Politics & Patronage-adjacent favor" without specifying the actual mechanism or cost.
- **Whether a rival household can contest ownership of a specific, desirable Road Segment** the way Business Competition or Land Ownership's own contested-plot mechanics already allow for other assets — not addressed here.
- **The exact prestige/wealth threshold for §8's New Road Founding**, beyond the general statement that it's this document's own rarest tier — left deliberately unsized alongside everything else, but worth flagging as needing an unusually high bar specifically so it doesn't become a routine action.
